# SLIMR

SLIMR (Simple Lightweight Inert Mass Rebalance) is a mod for Kerbal Space Program which adjusts the dry mass of all parts according to their type, as well as making some changes to particular parts, to achieve rocket mass fractions similar to reality.

## Dependencies

- [ModuleManager (4.2.3)](https://github.com/sarbian/ModuleManager)

## Compatibility

This mod should be compatible with most part mods, and has additionally been explicitly patched for compatibility with the following:

- [B9PartSwitch (1.1.0)](https://github.com/KSPModStewards/VABOrganizer)
- [Bluedog Design Bureau (1.14.0)](https://github.com/CobaltWolf/Bluedog-Design-Bureau)
- [Chemical Propulsion (1.6.2)](https://github.com/CharleRoger/ChemicalPropulsion)
- [Chemical Core (1.5.0)](https://github.com/CharleRoger/ChemicalCore)
- [Cryogenic Tanks (1.6.7)](https://github.com/post-kerbin-mining-corporation/CryoTanks)
